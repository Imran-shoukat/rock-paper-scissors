Rock, Paper, Scissors
A simple Rock, Paper, Scissors game built with Python and Tkinter.

Features
Graphical user interface
Player selection using radio buttons
Random computer moves
Automatic winner detection
Player and computer score tracking
Requirements
Python 3
Tkinter
How to Run
Clone this repository.
Open a terminal in the project directory.
Run:
   python rock_paper_scissors.py
Technologies Used
Python
Tkinter
Random module
Purpose
This project demonstrates basic Python programming, GUI development, conditional logic, and score tracking.
