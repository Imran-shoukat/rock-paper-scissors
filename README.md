# 🎮 Rock, Paper, Scissors Game

A simple Rock, Paper, Scissors game built with Python and Tkinter.

## ✨ Features
* **Graphical User Interface:** Clean and easy-to-use window layout.
* **Player Selection:** Simple radio buttons to choose Rock, Paper, or Scissors.
* **Random Computer Moves:** Smart and random AI opponent generation.
* **Automatic Winner Detection:** Instant result calculation for every round.
* **Score Tracking:** Keeps a running tally of both Player and Computer wins.

## 🛠️ Requirements
* Python 3
* Tkinter (usually bundled natively with Python installations)

## 🚀 How to Run
1. Clone this repository to your local computer.
2. Open a terminal or command prompt inside the project directory.
3. Launch the game by running:
   ```bash
   python rock_paper_scissors.py
   ```

## ⚙️ Technologies Used
* **Python** — Core program execution and conditional logic.
* **Tkinter** — Visual interface and graphical components.
* **Random Module** — Simulating un-biased computer choices.

## 🎯 Purpose
This project serves as a practical demonstration of basic Python fundamentals, software GUI layout flows, state evaluation, and basic dynamic variables updates.
